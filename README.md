# AI Virtual Air Canvas

An AI-powered virtual drawing application that allows users to draw in the air using hand gestures through a webcam.

## Features
- Hand Gesture Drawing
- Multiple Drawing Colors
- Adjustable Brush Size
- Adjustable Eraser Size (5–100)
- Background Selection
- Undo and Redo
- OCR Handwriting Recognition
- PNG and JPG Export
- Drawing Gallery

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Pytesseract

## How to Run
1. Install required libraries.
2. Keep hand_landmarker.task in the project folder.
3. Run:

python app.py
